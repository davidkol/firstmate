# HANDOFF Phase

> Session-end bookkeeping. Run this before ending any orchestrator session.

## Checklist

1. **Update the baton** (`docs/baton.md`):
   - Decisions made this session (with REQ/AP citations)
   - Open questions for next session
   - Briefs written or dispatched
   - What the next session should do first

2. **Update bookkeeping** (only if no worktrees are still outstanding):
   - `PROJECT_STATE.md` — system status changes, metric updates
   - `BACKLOG.md` — resolved items archived, then removed; new items added

3. **Summarize for the user:**
   - What was accomplished
   - What remains
   - Any decisions that need user input before next session
